# ElementalSpellCompiler
Trabalho da disciplina de Compiladores — DSL para criação, composição e execução de feitiços elementais usando PLY (Lexer + Parser + análise semântica).

## Funcionalidades

- entidades
- técnicas simples
- técnicas compostas
- composição recursiva
- técnicas inline
- validação semântica
- execução via `usar`

## Estrutura

src/ → lexer e parser

docs/ → gramática, árvores e documentação formal

## Execução

```bash
python parser.py
